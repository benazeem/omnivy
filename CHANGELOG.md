# Changelog

All notable changes to Omnivy are documented here.

## v2.0.0 - 2026-06-04

- Rebuilt Omnivy as a browser-first extension plus Next.js web app.
- Added Manifest V3 extension popup, settings page, background service worker, and content script.
- Added site-aware knowledge extraction with GitHub file, GitHub issue, Stack Overflow, forum, AI conversation, Notion, video, and generic strategies.
- Added editable clip properties and custom properties in the popup.
- Added Obsidian local save flow.
- Added cloud save flows for Google Drive, OneDrive, Dropbox, and Notion.
- Added provider status, folder loading, destination loading, and Notion destination management.
- Added extension auth/session bridge through Omnivy Web.
- Added encrypted provider token storage and refresh handling.
- Added context-menu save support.
- Added behavior settings for popup/background save behavior, image saving, and content links.
- Added public web pages for install, documentation, integrations, profile, request/feedback, roadmap, developer, privacy policy, and terms.
- Added Chrome Web Store listing stats and review fallback support on the install page.
- Added web app manifest and improved root metadata/JSON-LD.

## v1 Legacy

- Original native-messaging-style Obsidian-focused extension history.
- Preserved for reference and historical comparison.
